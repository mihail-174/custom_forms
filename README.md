# Custom Forms v3.0.0

[Перейти на сайт](https://mihail174.ru/docs/developments/custom_forms)

## Changelogs
1. Добавлена возможность включать или отключать добавление маски к полю телефона.


2. Включать или отключать блокировку кнопки "отправить" перенесена в настройки.


3. Добавление пометки "*" в лейблы полей и в плейсхолдер.


4. Добавлена валидация для полей: логин, пароль, повторить пароль.


5. Добавлена возможность использования гугл капчи и получение токена. Ключ для капчи указывается в настройках.


6. Изменена маска для телефона.


7. Добавлена возможность отправки данных формы по api.

8. Добавлено открытие попапа при успешной и не успешной отправки формы.

[Перейти к настройкам](https://mihail174.ru/docs/developments/custom_forms)
